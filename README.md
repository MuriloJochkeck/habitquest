# HabitQuest

Planejamento de uma **nova aplicação de controle de hábitos**, com Flutter, BLoC e uma API Python/Flask desenvolvida para o projeto.

O aplicativo ajudará a criar hábitos, registrar realizações diárias e acompanhar frequência, com XP, níveis e conquistas por consistência e metas cumpridas.

Consulte a [análise e o planejamento completo](docs/PLANEJAMENTO.md), incluindo análise da referência, escopo, arquitetura, contratos da API, regras de gamificação, direção visual, etapas e roteiro da avaliação.

**Estado atual:** análise e planejamento. Aplicativo, API, banco e testes ainda não foram implementados. As estruturas e os exemplos do documento são propostas para a implementação.
